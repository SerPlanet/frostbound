# Glossar

**Zweck:** Einheitliche Begriffe für alle Dokumente und Agenten.
**Zielgruppe:** Alle.
**Abhängigkeiten:** keine.

| Begriff | Bedeutung |
|---|---|
| Zug | Besteht im Prototyp aus einer Lokomotive und einem Wagon (D-005). Steht während eines Spieltages still am unteren Spielfeldrand (D-034). |
| Zugteil | Lokomotive oder Wagon. Jedes Zugteil hat eigene Lebenspunkte (D-041). |
| Lokomotive | Zugteil. Im ersten Prototyp ohne besondere Zusatzfunktion (D-041). |
| Wagon | Zugteil. Kann zerstört werden und verliert dann seine Funktion (D-041). |
| Zuggeschütz | Automatische Waffe des Zuges mit dem gesamten Spielfeld als Reichweite (D-037). Montageort und Anzahl OPEN (Q-025). |
| Zugziel | Das Zugteil, das ein Gegner ansteuert. Gewählt zufällig zwischen Lokomotive und Wagon (D-039). |
| Zerstört / vollständig zerstört | Lebenspunkte eines Zugteils sind aufgebraucht. Zerstörte Teile sind keine gültigen Gegnerziele (D-039). |
| Beschädigt | Zugteil mit verringerten, aber nicht aufgebrauchten Lebenspunkten. Behält seine Funktion (D-041). |
| Reparaturbereich | Sichtbarer Bereich je reparierbarem Objekt. Anwesenheit des Spielers repariert automatisch (D-043). |
| Spielfeld / Spielbereich | Fläche oberhalb des Zuges, auf der sich Spieler und Gegner bewegen (D-034). |
| Sichtbarer Bereich | Der auf dem Bildschirm sichtbare Teil. Gegner dürfen außerhalb davon starten (D-013, D-034). Abmessungen OPEN (Q-011). |
| Durchbruch | Ein Gegner erreicht sein Zugziel, verursacht Schaden und despawnt (D-015). |
| Besiegt | Ein Gegner wird durch Spieler oder Zuggeschütz ausgeschaltet. Ob Durchbrüche für den Sieg als „erledigt“ zählen: OPEN (Q-024). |
| Gruppe | Mehrere Gegner, die gemeinsam oder dicht hintereinander spawnen (D-017). |
| Welle / große Welle | Angriffsphase mit hoher Belastung. Der Prototyp enthält eine größere Angriffswelle ohne Bossmechanik (D-019). Die Abgrenzung zur „Gruppe“ ist durch Werte zu fixieren (Q-018). |
| Intensität | Anzahl der Gegner pro Zeit in einer Phase (D-017). |
| Runde | Ein Spieldurchlauf im Prototyp vom Start bis Sieg oder Niederlage. Die Beziehung zum Begriff „Spieltag“ ist nicht ausdrücklich festgelegt (Q-030). |
| Spieltag | Begriff aus der Langzeitvision (24 Tage). Der Zug steht während eines Spieltages still (D-034). |
| Greybox | Darstellung mit einfachen geometrischen Platzhaltern statt finaler Grafiken (D-006). |
| Tuning-Wert | Zahlenwert, der anhand von Tests angepasst wird und vorläufig ist (D-045). |
| REQ / D / Q | Anforderungs-ID / Entscheidungs-ID / ID einer offenen Frage. |
