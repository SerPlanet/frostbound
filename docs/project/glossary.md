# Glossar

**Zweck:** Einheitliche Begriffe für alle Dokumente und Agenten.
**Zielgruppe:** Alle.
**Abhängigkeiten:** keine.

| Begriff | Bedeutung |
|---|---|
| Zug | Besteht im Prototyp aus einer Lokomotive und einem Wagon mit einem Geschütz (D-005, D-054). Steht während eines Spieltages still am unteren Spielfeldrand (D-034). |
| Zugteil | Lokomotive oder Wagon (das Geschütz ist ein Bauteil des Wagons und kein eigenes Gegnerziel). Jedes Zugteil hat eigene Lebenspunkte (D-041). |
| Intakt | Ein Zugteil ist intakt, wenn es nicht zerstört ist, auch wenn es beschädigt ist (D-050). |
| Abgearbeitet | Ein Gegner ist abgearbeitet, wenn er besiegt wurde oder sein Ziel erreicht, dort Schaden verursacht hat und verschwunden ist (D-050). |
| Lokomotive | Zugteil. Steht immer ganz rechts am Zug, ihre Front zeigt nach rechts, in Fahrtrichtung (D-061). Im ersten Prototyp ohne besondere Zusatzfunktion (D-041). |
| Wagon | Zugteil. Steht links von der Lokomotive, weitere Wagen kämen links dazu (D-061). Kann zerstört werden und verliert dann seine Funktion (D-041). |
| Fahrtrichtung | Der Zug fährt immer von links nach rechts (D-061). |
| Zuggeschütz | Automatische Waffe auf dem Wagon mit dem gesamten Spielfeld als Reichweite, 20 HP. Zerstört, wenn der Wagon zerstört ist (D-037, D-054, D-055). |
| Zugziel | Das Zugteil, das ein Gegner ansteuert. Gewählt zufällig unter den intakten Zugteilen (D-051). |
| Zerstört / vollständig zerstört | Lebenspunkte eines Zugteils waren 0. Der Status bleibt bis zum vollständigen Reparaturabschluss, auch wenn die Lebenspunkte währenddessen steigen. Zerstörte Teile sind keine gültigen Gegnerziele (D-039). |
| Beschädigt | Zugteil mit verringerten, aber nicht aufgebrauchten Lebenspunkten. Behält seine Funktion (D-041). |
| Reparaturzone / Reparaturbereich | Bereich je reparierbarem Zugteil, angezeigt nur wenn das Teil repariert werden kann. Anwesenheit des Spielers repariert automatisch, 5 HP je 5 s (D-043, D-056). |
| Spielfeld / Spielbereich | Fläche oberhalb des Zuges, auf der sich Spieler und Gegner bewegen (D-034). |
| Sichtbarer Bereich | Der auf dem Bildschirm sichtbare Teil. Gegner dürfen außerhalb davon starten (D-013, D-034). Logische Größe: TECH-01. |
| Durchbruch | Ein Gegner erreicht sein Zugziel, verursacht Schaden und despawnt (D-015, D-052). Er zählt als abgearbeitet. |
| Besiegt | Ein Gegner wird durch Spieler oder Zuggeschütz ausgeschaltet. Besiegt ist eine Form von abgearbeitet. |
| Gruppe | Mehrere Gegner, die gemeinsam oder dicht hintereinander spawnen (D-017). |
| Welle / große Welle | Angriffsphase mit hoher Belastung. Der Prototyp enthält eine größere Angriffswelle ohne Bossmechanik (D-019). Die Abgrenzung zur „Gruppe“ ist durch die Testwerte des Wellenplans festgelegt (difficulty.md). |
| Intensität | Anzahl der Gegner pro Zeit in einer Phase (D-017). |
| Runde | Ein Spieldurchlauf im Prototyp vom Start bis Sieg oder Niederlage. Die Beziehung zum Begriff „Spieltag“ ist nicht ausdrücklich festgelegt (Q-030). |
| Spieltag | Begriff aus der Langzeitvision (24 Tage). Der Zug steht während eines Spieltages still (D-034). |
| Greybox | Darstellung mit einfachen geometrischen Platzhaltern statt finaler Grafiken (D-006). |
| Tuning-Wert / TESTWERT | Zahlenwert, der anhand von Tests angepasst wird und vorläufig ist (D-045). |
| TECH | Technische Entscheidung des ausführenden Agenten im Rahmen von D-060, revidierbar, ohne Änderung bestätigter Gameplay-Regeln. |
| REQ / D / Q | Anforderungs-ID / Entscheidungs-ID / ID einer offenen Frage. |
